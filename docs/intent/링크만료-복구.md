# 링크 만료 복구

## 목표 (Why)
- 실전 시험 중 연결이 5분(유예)을 넘게 끊겨 만료된 응시자의 입장 링크를, 담당자가 콘솔에서 복구해 같은 링크로 이어서 응시하게 한다.
- 지금은 `ExamParticipant.linkExpiredAt`을 지우는 코드가 없고, `reissueInvite`(초대 재발송)도 지우지 않아 만료되면 되돌릴 방법이 없다. 와이파이가 잠깐 끊긴 응시자가 시험 전체를 잃는다.

## 확정한 내용
- 복구 권한: 매니저·감독관·관리자 (콘솔 권한 전체). 자기 회사 회차만 (`ConsoleAccess.requireSession` 기준).
- 완료 기준
  - 복구하면 `enter`·`start`·`heartbeat`가 다시 통과하고 종료 시각까지 이어서 풀 수 있다.
  - 복구하면 `lastSeenAt`을 지금으로 맞춰 바로 다시 만료되지 않게 한다.
  - 누가·언제 복구했는지 `LINK_EXPIRED`와 별개인 새 감독 이벤트로 남긴다.
- 제약
  - 종료 시각은 모두 같고 연장하지 않는다. 끊긴 동안 흐른 시간은 돌려주지 않는다.
  - 이미 제출했거나 회차가 끝난 응시자는 복구하지 못한다.
  - 복구 횟수 제한은 두지 않는다.

## 하지 않을 것 (Out of scope)
- 시험 시간 연장
- 5분 유예 기준값 변경
- 프론트 15초 채널 차단과 서버 연결 기준 통일 (별도 항목)
- 같은 링크 중복 접속 감지
