# 감독관 → 응시자 메시지

## 목표 (Why)

실전 시험 중 감독관이 카메라 이벤트(시선 이탈, 고개 돌림 등)를 보고도 응시자에게 알릴 방법이 없다. 감독관이 경고 문구를 보내면 응시자 화면 위쪽에 배너가 뜨고, 응시자는 문제를 계속 풀면서 "확인"만 눌러 닫는다.

- 대상: 보내는 쪽은 감독관(콘솔), 받는 쪽은 시험 중인 응시자.
- 문구: 준비된 문구를 고르거나 직접 입력한다.
- 성공 기준:
  1. 감독관이 준비된 문구를 고르거나 직접 입력해서 보낼 수 있다.
  2. 응시자 화면에 배너가 뜨고, "확인"을 누르면 닫힌다.
  3. 단순 알림이므로 보낸 기록, 확인 시각, "읽음" 표시는 어디에도 남기지 않는다.
- 제약:
  1. 백엔드와 프론트를 모두 건드린다.
  2. 개발 환경 기준으로 먼저 만든다.
  3. 전달 방식(폴링, 실시간 연결 등)은 기존 구조를 보고 구현 단계에서 정한다.

## 하지 않을 것 (Out of scope)

- 응시자 답장, 채팅
- 화면 전체를 가리는 모달
- 음성·영상 전달
- 여러 응시자에게 한꺼번에 보내는 기능
- 확인을 안 눌렀을 때 시험을 자동으로 막거나 감점하는 처리
- 메시지 기록과 읽음 확인 (감독관 화면, 이벤트 타임라인 모두)
