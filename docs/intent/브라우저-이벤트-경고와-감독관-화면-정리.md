# 의도: 실시간 영상 보기 끄기, 브라우저 이벤트 경고화, 감독관 화면 정리

> 상태: 사용자가 2026-11-24 확정 (interview-me).
> 관련 문서: [감독관-실시간-보기-운영-시그널링.md](감독관-실시간-보기-운영-시그널링.md), [API §6-11·§7](../../API/실전시험_감독_API.md)

## 목표 (Why)

다른 네트워크 시험에서 응시자가 핫스팟일 때 실시간 영상 연결(ICE)이 실패하는 경우가 확인됐다(STUN만 사용, TURN 없음). 실시간 영상은 쓰지 않고, 이벤트 기록과 사진 증거 중심으로 감독을 단순하게 정리한다. 감독관이 보는 정보는 알아보기 쉽게 하고, 응시자에게 불필요한 이탈 경고가 생기지 않게 한다.

## 확정한 내용

1. **실시간 영상 보기 끄기**: 웹캠과 화면 공유 모두 스위치로 끈다. 감독관 화면에서 "영상 보기"가 사라지고 서버 `watch` 도 거절한다. 코드·서버 시그널링·문서는 남겨 두고 스위치를 켜면 되살릴 수 있다. 화면 공유 자체는 응시자 쪽에서 유지하고 중단·재시작 이벤트만 기록한다.
2. **브라우저 이벤트(탭 전환, 창 이탈·흐려짐, 마우스 이탈, 전체 화면 해제, 붙여넣기)**: 응시자에게 경고를 보여 주고, 감독관 콘솔에는 **발생 시각 같은 이력만** 보여 준다. 확정/기각(검수)은 없앤다.
3. **마우스 이탈 규칙**: 위·아래 가장자리로 나가는 것은 이탈로 세지 않고 **좌우만** 센다. 화면 공유 여부와 관계없이 항상 적용한다. 이유: 전체 화면의 ESC "X" 버튼(위쪽)과 화면 공유 안내 막대(웨일·크롬 전체 화면 공유는 아래쪽, 탭 공유는 위쪽)에 마우스가 가는 것을 막기 위해서이고, 창 이탈은 별도로 감지한다.
4. **환경 점검 내용**: 감독관 콘솔에서 응시자를 열 때 보이던 환경 점검 부분은 빼고 **"점검 미통과" 탭에서만** 본다.
5. **이벤트 앞뒤 사진**: 부정행위 이벤트를 확인하는 앞뒤 사진은 **웹캠 사진만** 남긴다(휴대폰 프레임 제외).
6. **카메라 이벤트 세부 내용**: 시선 벗어남·고개 움직임·얼굴 수 등의 세부 내용을 좌표 숫자 대신 **문장**("시선이 오른쪽으로 31% 치우침 (기준 45% 넘으면 경고)")으로 바꾼다. **원본 숫자는 숨긴다**(스냅샷이 함께 보이므로). 고개 좌우 방향은 코드에 기준이 없어 "좌우로"라고만 쓰고, 방향은 구현 때 실제 카메라로 확인해 정한다.

## 하지 않을 것 (Out of scope)

- 실시간 보기 코드·서버 시그널링·문서를 지우지 않는다.
- 카메라 이벤트(얼굴 없음, 시선, 고개 등)의 확정/기각은 그대로 둔다.
- 화면 공유 이벤트 저장(중단, 재시작)은 그대로 둔다.
- 휴대폰 캠 켜기/끄기 정책과 TURN 은 다루지 않는다.
