# 내 담당 쉽게 정리 (팀원 4: 실전 시험 흐름)

> 2026-11-19 작성, **2026-11-23 현재 정책 기준으로 갱신**. 자세한 설계·코드 위치·실행 방법·테스트 결과는 [담당_기술명세_상혁.md](담당_기술명세_상혁.md), API 는 [실전시험_감독_API.md](../API/실전시험_감독_API.md).

## 1. 한 줄 요약

**기업이 시험 회차를 열고 → 지원자가 감독을 받으며 같은 시각에 시험을 보고 → 끝나면 자동 제출되고 → 기업이 결과를 보는 흐름 전체**를 맡는다.
감독은 영상을 서버로 보내지 않는다. 응시자 PC 브라우저 안에서 분석하고, 이상한 순간의 기록 1건과 사진 1장만 보낸다.

## 2. 흐름 그림

```
기업 담당자                       응시자                               서버
───────────                       ──────                               ────
회차 만들기 (과제 여러 개, 시각)
대상자 CSV 올리기 ──────────────────────────────────────────▶ 초대 메일 (입장 링크)
                                  메일 링크 클릭
                                  동의 + 환경 점검 (카메라·화면 공유)
                                     └ 점검 진행 상태 3초마다 ──▶ 콘솔이 실시간으로 확인, 안내 메시지 전송
                                     └ 실패해도 저장하고 입장 ──▶ 감독 기록에 남김 (감독관이 판단)
                                  대기실 (서버 시각 카운트다운)
                                  시작 ◀──────────────────────── 서버 시각이 되면 허락
                                  풀이 + 감독 (브라우저 안 분석, 10초마다 연결 신호)
                                     └ 이상 순간만 ─────────────▶ 이벤트 1건 + 사진 1장 저장
                                     └ 5분 넘게 끊기면 ──────────▶ 링크 만료 기록
                                  과제별 제출 ──────────────────▶ 채점 큐 (팀원 1)
                                                               종료 시각: 남은 과제 자동 제출
결과 보기 (순위·분포·감독 요약)
이벤트 판정 (OK / 부정 의심)
```

## 3. 구현된 기능

| 기능 | 하는 일 | 상태 |
|---|---|---|
| 회차 만들기·수정·취소 | 시작 전에만 고칠 수 있음. 취소해도 지우지 않고 기록을 남기고, 대상자에게 안내 메일 | ✅ |
| 대상자 등록 | 사이트 양식 CSV·엑셀 업로드. 올리기 전에 미리 보기(틀린 줄·중복 표시), 원본 파일 보관 | ✅ |
| 메일 | 등록 즉시 초대, 시작 하루 전 알림, 변경·취소 안내. 다시 보내면 새 링크(이전 링크 무효) | ✅ |
| 입장 | 메일 링크 → 시험 정보 → 동의·환경 점검 → 대기실 (입장 마감 없음) | ✅ |
| 환경 점검 | PC(브라우저·모니터·카메라·소음·조명·자세·귀·손목). 휴대폰 점검(조명·책상 위)은 휴대폰 캠이 꺼져 있는 동안 나오지 않음. **실패·경고여도 저장하고 입장**(AI 판정 오류로 막히지 않게), 감독관이 확인. 다시 점검하면 **통과하지 못한 항목만** 다시 | ✅ |
| 점검 콘솔 확인·안내 메시지 | 콘솔 대상자 상세에서 점검 항목별 상태·사유를 실시간으로 보고, 응시자에게 일방향 안내(최대 500자)를 보내 읽음 표시를 봄 | ✅ (실제 동시 사용은 사람이 아직 확인 못 함) |
| 감독 이벤트 알림 | 새 이벤트가 오면 알림음과 새 이벤트 모음, 응시자 영상 확대 보기 | ✅ |
| 연결 필수·유예 | **현재 웹캠 + PC 화면 공유**가 모두 연결돼야 응시, 끊기면 15초 유예 뒤 응시 화면 차단. 서버는 10초마다 연결 신호를 받아 90초 끊김 기록, 5분 넘으면 링크 만료 | ✅ (서버에 화면 공유 이벤트는 아직 안 보냄. 휴대폰 보조 캠은 스위치로 꺼짐, 화면 공유는 11-23 재활성화) |
| 사전 테스트 | `/practice` 에서 실제와 같은 점검을 연습. 서버에 아무것도 남기지 않음 | ✅ |
| 늦은 입장·새로고침 복구 | 시작 시각이 지나도 종료 전이면 입장해 시작할 수 있고, 새로고침하면 대기실에서 웹캠을 다시 연결해 이어 간다 | ✅ |
| 감독 분석 부하 제한 | 웹캠 분석을 초당 10회 이하로 제한하고 얼굴·포즈 모델을 번갈아 돌려 시험 화면 입력이 덜 끊기게 함 | ✅ |
| 동시 시작 | 서버 시각이 시작 시각이 돼야 시작. 두 번 눌러도 응시는 하나 | ✅ |
| 과제별 제출 | 과제 하나씩 제출, 다 내면 "제출 완료" | ✅ |
| 자동 제출 | 종료 시각이 지나면 2초 안에 남은 과제를 서버가 전부 제출 | ✅ |
| 브라우저 감독 | 탭 이동, 창 이동, 마우스 이탈, 전체 화면 해제, 외부 붙여넣기 감지 → 회차 감독 기록에 함께 저장 | ✅ |
| PC 카메라 감독 | 얼굴 없음, 여러 사람, 고개 돌림·숙임, 시선 이탈, 자리 이동 | ✅ (실제 카메라 테스트는 아직) |
| 휴대폰 보조 캠 | **사용 중단(11-21, `PHONE_CAM_ENABLED=false`)**. 코드는 남아 있고 켜면 QR 로 연결해 영상만 보내고 PC 가 책상 스캔·손·휴대폰·책·다른 화면을 감시 | ⏸ 꺼짐 |
| PC 화면 공유 (**켜짐**) | 동의 후 "전체 화면" 공유, 중단·부분 공유 감지, 이벤트 순간 흐린 사진 1장(서버 저장은 백엔드가 받을 때) | ✅ 프론트 / ⬜ 서버 저장 |
| 감독관 영상 보기 | 감독관이 응시자를 열었을 때만 웹캠·화면 영상을 P2P 로 보여 줌(저장 없음, 응시자당 2명) | ✅ 개발 릴레이만 / ⬜ 운영 |
| 사진 보관 | 이상 순간 사진 1장, 회차 종료 7일 뒤 자동 삭제 (서버 설정값 30 → 7 변경 필요) | ⚠️ |
| 담당자 판정 | 이벤트마다 OK / SUSPECT(부정 의심) 표시. 자동 탈락 없음 | ✅ |
| 회차 결과 | 순위, 점수 분포, 역량별 평균, 상·하위 비교, 감독 요약, CSV·엑셀 내보내기 | ✅ |
| 기업 콘솔 화면 | 회차 목록·만들기·수정·취소, 대상자 추가·CSV·빼기·재발송, 실시간 현황, 결과, 감독 사진·판정이 실제 서버로 동작 | ✅ |
| 로그인·회사 분리 | 콘솔 API 가 로그인한 사람의 회사 회차만 다룸 (다른 회사 404, 역할 없으면 403) | ✅ 경계 (실제 로그인은 팀원 1) |
| 관리자 과제 콘솔 | 과제 목록, 공개·숨기기, 용도 변경, 검수용 파일·문항·자료 보기. 회차에는 공개한 실전 과제만 | ✅ |
| 오탐률 측정 도구 | 조명·각도·안경을 고르고 N분 정상 응시 → 규칙별 분당 오탐 수, 기준값 버전별 비교, CSV | ✅ (`/proctor/lab`, 실제 측정은 직접) |

**아직 안 한 것:** 실제 카메라·휴대폰으로 전체 흐름 확인과 조건별 오탐률 측정(사람이 직접, 체크리스트는 pAIr-front `docs/plan/real-device-checklist.md`), 서버의 영상 이벤트 재확인(`serverCheck`), 화면 공유 이벤트 서버 저장(`SCREEN`), 운영용 휴대폰 릴레이·감독관 영상 시그널링(개발 릴레이만 있음), 분석 중단 감지, 콘솔의 AI 대화 수·마지막 활동 표시(응시 기록 API). 사진 보관은 7일로 확정했고(동의 문구와 같음) 서버 설정값(지금 30)만 7 로 바꾸면 된다. 안내 메시지가 응시자 화면에 뜨는 시간은 실측하지 않았고, 점검에 실패한 채 입장한 사람만 모아 보는 화면은 없다. 개발 서버의 "안전하지 않음"(자체 서명 인증서) 경고는 배포 후 정식 인증서로 다시 검증하고, 새로고침 뒤 대기실에서도 연결 신호를 보내는 개선은 제안 단계다.

## 4. 기술 스택

### 백엔드 (서버)

| 이름 | 무엇인가 | 여기서 하는 일 |
|---|---|---|
| **Java 21** | 프로그래밍 언어 | 서버 코드 |
| **Spring Boot 3.5** | 자바로 웹 서버를 빨리 만드는 틀(프레임워크) | API, 설정, 스케줄러, 메일을 한 번에 |
| **Spring Data JPA** | 자바 객체 ↔ DB 표를 자동으로 이어 주는 도구 | 회차·대상자·이벤트를 저장하고 조회 |
| **PostgreSQL** | 데이터베이스 (개발·운영 모두 AWS RDS, 접속 정보는 `pAIr-back/application-secret.yml`) | 회차, 대상자, 동의, 감독 이벤트 저장 |
| **Flyway** | DB 구조 변경 이력 관리 도구 | `V1`~`V19` SQL 파일을 순서대로 적용(내 담당은 V1·V2·V11·V14·V19). 서버가 켜질 때 자동 |
| **@Scheduled** | 스프링의 "주기적으로 실행" 기능 | 2초마다 자동 제출, 30초마다 연결 유예 점검, 5분마다 알림 메일, 1시간마다 사진 정리 |
| **Spring Mail** | 메일 보내기 기능 | 초대·알림·안내 메일 |
| **@Async + 커밋 뒤 이벤트** | 저장이 끝난 뒤 다른 스레드에서 실행 | 1000명 등록해도 응답은 바로, 메일은 뒤에서 |
| **AWS S3** | 아마존 파일 저장소 | 감독 사진, 대상자 CSV 원본 (개발 중엔 로컬 폴더) |
| **JUnit 5 + H2** | 테스트 도구 + 메모리 DB | 자동 테스트 (Docker 없이 돌아감) |

## 5. 감독에 쓰는 AI 모델 (모두 응시자 브라우저 안에서 실행)

| 모델 | 무엇을 보는가 | 어디에 쓰나 |
|---|---|---|
| **MediaPipe Face Landmarker** | 얼굴 점 478개, 얼굴 기울기, 눈 깜빡임·시선 | 얼굴 없음, 여러 얼굴, 고개 돌림, 시선 이탈 |
| **MediaPipe Pose Landmarker** | 어깨·몸통 위치 | 자리 이동, 몸 돌림 |
| **MediaPipe Hand Landmarker** | 손 위치 | 환경 점검: 손목 확인 (휴대폰 캠을 켜면 양손이 화면 밖으로 벗어남도) |
| **MediaPipe Object Detector (EfficientDet-Lite0)** | 물체 찾기 (휴대폰, 노트북, 책 등) | 휴대폰 캠을 켰을 때: 휴대폰·다른 화면·책, 책상 위 스캔(처음 한 번만 불러와 재사용) |

- **MediaPipe**: 구글이 만든 브라우저용 영상 분석 도구. 컴퓨터 GPU 로 빠르게 돈다 (`@mediapipe/tasks-vision`). 휴대폰 영상도 **휴대폰이 아니라 응시자 PC 가** 분석한다.
- 얼굴로 **누구인지 알아보지 않는다.** 얼굴이 있는지, 어디를 보는지만 본다 → 생체정보를 다루지 않음.

## 6. 자주 나오는 용어

| 용어 | 뜻 |
|---|---|
| **회차** | 시험 한 번. 시작·종료 시각과 과제 여러 개를 가진다 |
| **대상자** | 회차에 초대된 응시자 |
| **응시(attempt)** | 대상자가 과제 하나를 푸는 기록. 과제마다 1개 |
| **초대 토큰** | 메일 링크에 들어 있는 43자 비밀값. 로그인 대신 본인 확인 |
| **해시(SHA-256)** | 값을 되돌릴 수 없게 바꾼 지문. DB 에는 토큰 대신 이 지문만 저장 → DB 가 새도 링크를 못 만듦 |
| **서버 시각** | 응시자 PC 시계가 틀려도 모두 서버 시계로 판단 → 공정 |
| **행 잠금** | 같은 대상자 요청이 동시에 오면 줄 세우기. 시작 버튼을 두 번 눌러도 응시는 하나 |
| **아웃박스** | 브라우저가 감독 이벤트를 잠깐 쌓아 두는 곳. 인터넷이 끊겨도 나중에 다시 보냄 |
| **개인별 보정** | 시작 3초 자세를 "기준"으로 잡음. 카메라 각도가 달라도 오탐이 줄어듦 |
| **오탐** | 부정행위가 아닌데 경고가 뜬 것 |
| **짝 코드** | 휴대폰 QR 에 넣는 별도 코드. QR 이 찍혀도 입장 링크는 안 드러남 |
| **마이그레이션** | DB 표 구조를 바꾸는 SQL 파일 (`V2__erd_changes.sql`, `V11__connection_grace.sql`, `V14__env_scan_photos.sql`, `V19__env_check_notices.sql`) |
| **연결 유예** | 시험 중 연결이 끊겨도 기다려 주는 시간. 응시자 화면은 15초(웹캠·화면 공유), 서버는 5분(시험 화면 연결 신호). 넘으면 응시 화면 차단 / 링크 만료 |

| **CSV 주입 방지** | `=` `+` `-` `@` 로 시작하는 칸 앞에 `'` 를 붙여 엑셀이 수식으로 실행하지 않게 함 |

| **자동 제출 지연** | 종료 시각과 서버가 실제로 제출 처리한 시각의 차이. 목표 5초 이내 (테스트 0.8초) |
