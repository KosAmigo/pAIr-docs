# 내 담당 쉽게 정리 (팀원 4: 실전 시험 흐름)

> 2026-11-19 기준. 자세한 설계는 [담당_기술명세_상혁.md](담당_기술명세_상혁.md), API 는 [실전시험_감독_API.md](../API/실전시험_감독_API.md).

## 1. 한 줄 요약

**기업이 시험 회차를 열고 → 지원자가 감독을 받으며 같은 시각에 시험을 보고 → 끝나면 자동 제출되고 → 기업이 결과를 보는 흐름 전체**를 맡는다.
감독은 영상을 서버로 보내지 않는다. 응시자 브라우저 안에서 분석하고, 이상한 순간의 기록 1건과 사진 1장만 보낸다.

## 2. 흐름 그림

```
기업 담당자                       응시자                               서버
───────────                       ──────                               ────
회차 만들기 (과제 여러 개, 시각)
대상자 CSV 올리기 ──────────────────────────────────────────▶ 초대 메일 (입장 링크)
                                  메일 링크 클릭
                                  동의 + 환경 점검 (카메라·휴대폰)
                                  대기실 (서버 시각 카운트다운)
                                  시작 ◀──────────────────────── 서버 시각이 되면 허락
                                  풀이 + 감독 (브라우저 안 분석)
                                     └ 이상 순간만 ─────────────▶ 이벤트 1건 + 사진 1장 저장
                                  과제별 제출 ──────────────────▶ 채점 큐 (팀원 1)
                                                               종료 시각: 남은 과제 자동 제출
결과 보기 (순위·분포·감독 요약)
이벤트 판정 (OK / 부정 의심)
```

## 3. 구현된 기능

| 기능 | 하는 일 | 상태 |
|---|---|---|
| 회차 만들기·수정·취소 | 시작 전에만 고칠 수 있음. 취소해도 지우지 않고 기록을 남기고, 대상자에게 안내 메일 | ✅ |
| 대상자 등록 | 사이트 양식 CSV 업로드. 올리기 전에 미리 보기(틀린 줄·중복 표시), 원본 파일 보관 | ✅ |
| 메일 | 등록 즉시 초대, 시작 하루 전 알림, 변경·취소 안내. 다시 보내면 새 링크(이전 링크 무효) | ✅ |
| 입장 | 메일 링크 → 시험 정보 → 동의·환경 점검 → 대기실 | ✅ |
| 동시 시작 | 서버 시각이 시작 시각이 돼야 시작. 두 번 눌러도 응시는 하나 | ✅ |
| 과제별 제출 | 과제 하나씩 제출, 다 내면 "제출 완료" | ✅ |
| 자동 제출 | 종료 시각이 지나면 2초 안에 남은 과제를 서버가 전부 제출 | ✅ |
| 브라우저 감독 | 탭 이동, 창 이동, 마우스 이탈, 전체 화면 해제, 외부 붙여넣기 감지 → 회차 감독 기록에 함께 저장 | ✅ |
| PC 카메라 감독 | 얼굴 없음, 여러 사람, 고개 돌림·숙임, 시선 이탈, 자리 이동 | ✅ (실제 카메라 테스트는 아직) |
| 휴대폰 보조 캠 | QR 로 연결, 방·책상 스캔, 손·휴대폰·책 감시, 연결 끊김 기록 | ✅ |
| 사진 보관 | 이상 순간 사진 1장, 회차 종료 30일 뒤 자동 삭제 | ✅ |
| 담당자 판정 | 이벤트마다 OK / SUSPECT(부정 의심) 표시. 자동 탈락 없음 | ✅ |
| 회차 결과 | 순위, 점수 분포, 역량별 평균, 상·하위 비교, 감독 요약, CSV 내보내기 | ✅ |
| 기업 콘솔 화면 | 회차 목록·만들기·수정·취소, 대상자 추가·CSV·빼기·재발송, 실시간 현황, 결과, 감독 사진·판정이 실제 서버로 동작 | ✅ |
| 로그인·회사 분리 | 콘솔 API 가 로그인한 사람의 회사 회차만 다룸 (다른 회사 404, 역할 없으면 403) | ✅ 경계 (실제 로그인은 팀원 1) |
| 관리자 과제 콘솔 | 과제 목록, 공개·숨기기. 회차에는 공개한 과제만 | ✅ (내용 편집은 과제 DB 생기면) |
| 오탐률 측정 도구 | 조명·각도·안경을 고르고 N분 정상 응시 → 규칙별 분당 오탐 수, 기준값 버전별 비교, CSV | ✅ (`/proctor/lab`, 실제 측정은 직접) |

**아직 안 한 것:** 실제 카메라로 전체 흐름 확인과 조건별 오탐률 측정(사람이 직접), Spring Security 실제 로그인(팀원 1), 과제 내용 편집(과제 DB), 콘솔의 AI 대화 수·마지막 활동 표시(응시 기록 API).

> 콘솔은 기본으로 백엔드를 부른다. 서버 없이 화면 시안만 보려면 `VITE_CONSOLE_DATA=mock` 으로 켠다.

## 4. 기술 스택

### 백엔드 (서버)

| 이름 | 무엇인가 | 여기서 하는 일 |
|---|---|---|
| **Java 21** | 프로그래밍 언어 | 서버 코드 |
| **Spring Boot 3.5** | 자바로 웹 서버를 빨리 만드는 틀(프레임워크) | API, 설정, 스케줄러, 메일을 한 번에 |
| **Spring Data JPA** | 자바 객체 ↔ DB 표를 자동으로 이어 주는 도구 | 회차·대상자·이벤트를 저장하고 조회 |
| **PostgreSQL 17** | 데이터베이스 | 회차, 대상자, 동의, 감독 이벤트 저장 |
| **Flyway** | DB 구조 변경 이력 관리 도구 | `V1`, `V2` SQL 파일을 순서대로 적용. 서버가 켜질 때 자동 |
| **@Scheduled** | 스프링의 "주기적으로 실행" 기능 | 2초마다 자동 제출, 5분마다 알림 메일, 1시간마다 사진 정리 |
| **Spring Mail** | 메일 보내기 기능 | 초대·알림·안내 메일 |
| **@Async + 커밋 뒤 이벤트** | 저장이 끝난 뒤 다른 스레드에서 실행 | 1000명 등록해도 응답은 바로, 메일은 뒤에서 |
| **AWS S3** | 아마존 파일 저장소 | 감독 사진, 대상자 CSV 원본 (개발 중엔 로컬 폴더) |
| **JUnit 5 + H2** | 테스트 도구 + 메모리 DB | 자동 테스트 (Docker 없이 돌아감) |

## 5. 감독에 쓰는 AI 모델 (모두 응시자 브라우저 안에서 실행)

| 모델 | 무엇을 보는가 | 어디에 쓰나 |
|---|---|---|
| **MediaPipe Face Landmarker** | 얼굴 점 478개, 얼굴 기울기, 눈 깜빡임·시선 | 얼굴 없음, 여러 얼굴, 고개 돌림, 시선 이탈 |
| **MediaPipe Pose Landmarker** | 어깨·몸통 위치 | 자리 이동, 몸 돌림 |
| **MediaPipe Hand Landmarker** | 손 위치 | 휴대폰 캠: 손 이탈, 손 위치 이탈, 팔 움직임 |
| **MediaPipe Object Detector (EfficientDet-Lite0)** | 물체 찾기 (휴대폰, 노트북, 책 등) | 휴대폰 캠: 휴대폰·다른 화면·책 |
| **OWL-ViT** (Transformers.js) | 글로 적은 물체를 사진에서 찾기 ("메모지", "이어폰") | 환경 점검 사진의 정밀 분석. **"검토 필요" 표시만**, 자동 판정 안 함 |

- **MediaPipe**: 구글이 만든 브라우저용 영상 분석 도구. 컴퓨터 GPU 로 빠르게 돈다 (`@mediapipe/tasks-vision`).
- **Transformers.js**: AI 모델을 브라우저에서 돌리는 라이브러리 (`@huggingface/transformers`).
- 얼굴로 **누구인지 알아보지 않는다.** 얼굴이 있는지, 어디를 보는지만 본다 → 생체정보를 다루지 않음.

## 6. 자주 나오는 용어

| 용어 | 뜻 |
|---|---|
| **회차** | 시험 한 번. 시작·종료 시각과 과제 여러 개를 가진다 |
| **대상자** | 회차에 초대된 응시자 |
| **응시(attempt)** | 대상자가 과제 하나를 푸는 기록. 과제마다 1개 |
| **초대 토큰** | 메일 링크에 들어 있는 43자 비밀값. 로그인 대신 본인 확인 |
| **해시(SHA-256)** | 값을 되돌릴 수 없게 바꾼 지문. DB 에는 토큰 대신 이 지문만 저장 → DB 가 새도 링크를 못 만듦 |
| **서버 시각** | 응시자 PC 시계가 틀려도 모두 서버 시계로 판단 → 공정 |
| **행 잠금** | 같은 대상자 요청이 동시에 오면 줄 세우기. 시작 버튼을 두 번 눌러도 응시는 하나 |
| **아웃박스** | 브라우저가 감독 이벤트를 잠깐 쌓아 두는 곳. 인터넷이 끊겨도 나중에 다시 보냄 |
| **개인별 보정** | 시작 3초 자세를 "기준"으로 잡음. 카메라 각도가 달라도 오탐이 줄어듦 |
| **오탐** | 부정행위가 아닌데 경고가 뜬 것 |
| **짝 코드** | 휴대폰 QR 에 넣는 별도 코드. QR 이 찍혀도 입장 링크는 안 드러남 |
| **마이그레이션** | DB 표 구조를 바꾸는 SQL 파일 (`V2__exam_decisions.sql`) |
| **CSV 주입 방지** | `=` `+` `-` `@` 로 시작하는 칸 앞에 `'` 를 붙여 엑셀이 수식으로 실행하지 않게 함 |
| **데이터 절감률** | 실제 보낸 사진 용량 ÷ 영상으로 감독했다면 보냈을 양. 목표 99% 이상 절감 |
| **자동 제출 지연** | 종료 시각과 서버가 실제로 제출 처리한 시각의 차이. 목표 5초 이내 (테스트 0.8초) |
