## 큰 문제 목록

| 문제 | 해결 | 날짜 |
|---|---|---|
| 서버 재시작 때 채점 중이던 응시가 `SCORING` 에 남음 | 서버 시작 때 다시 채점에 맡김(24시간 한도 넘으면 ERROR) | 11-26 |
| 배포·종료 때 채점이 10초 만에 강제로 잘림 | graceful 종료 + 하던 채점 최대 90초 마무리 + Docker 대기 150초 | 11-26 |
| 동시 채점 수를 늘려도 처리량이 그대로(분당 약 5건) | 채점 모델 호출 스레드 고정 8개 → 동시 채점 수 × 호출 수 | 11-26 |
| 후속 질문 동시 제출 시 채점 두 번 시작 | 조건부 UPDATE 한 문장으로 상태 변경, 이긴 요청만 채점 | 11-26 |
| 큐를 켠 첫 배포가 health DOWN 으로 실패 | 운영 Redis 시작, compose 에서 Redis 프로필 제거 | 11-26 |
| Redis 하나가 죽어도 배포 확인이 막힘 | Redis 를 뺀 `/actuator/health/core` 로 배포 확인, 큐 장애는 지표·경고로 분리 | 11-26 |
| 휴대폰 폭에서 자가진단 화면이 905px 옆으로 밀림 | 자가진단 셸 화면만 `body` 최소 폭 1280px 해제, 머리 두 줄 | 11-26 |
| 환불이 토스 결제를 취소하지 않음(모의 환불) | `REFUNDING` → 토스 취소 → `REFUNDED`, 거절 시 크레딧 되돌림, 결과 모르면 새 키로 이어서 | 11-27 |
| 채팅 제한을 스트림 안에서 걸면 429 를 줄 수 없음 | 스트림을 열기 전에 컨트롤러에서 확인 | 11-27 |
