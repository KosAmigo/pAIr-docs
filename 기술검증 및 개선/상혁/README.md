## 지금 남은 일 (2026-11-24 기준)

- 실제 카메라로 전체 흐름(웹캠 + 화면 공유 + 휴대폰 캠)을 사람이 직접 확인하는 일 (체크리스트: pAIr-front `docs/plan/real-device-checklist.md`). 새로 들어간 화면 공유 이벤트(중단·창만 공유·재시작)와 콘솔 "점검 미통과" 탭도 여기서 같이 본다
- 조건(조명·각도·안경)별 오탐률 실측과 기준값 조정 전후 비교, 영상 대비 데이터 절감률 실측
- Worker 분리·성능 자가 측정을 실제 카메라·저사양 PC·Firefox/Safari·운영 번들(CSP)에서 확인
- 휴대폰 JPEG 프레임 중계·증거 구간·보관 연장의 실기기 확인과 서버 상한 실측 — [API §7](../../API/실전시험_감독_API.md)
- 안내 메시지가 응시자 화면에 뜨는 시간(폴링 주기) 실측
- 감독관 실시간 보기(운영 시그널링, 11-24 구현)를 개발 PC 두 대·실제 카메라로 확인하는 일, TURN 없이 영상이 안 나오는 네트워크 비율 확인
- 휴대폰 릴레이 서버 확장(여러 대 대응·상한 실측)은 별도 작업

> 11-24 에 닫은 것: API §7 최적안(채널별 12장·1초 간격·본문 2MB·종료된 회차만 연장·`quality` 중계)은 코드에 이미 있었음을 확인했고, 화면 공유 이벤트 서버 저장과 점검 미통과 입장자 모음 화면을 구현했다 — [2026-11-24.md](2026-11-24.md)
