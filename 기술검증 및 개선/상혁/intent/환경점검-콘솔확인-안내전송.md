# 환경 점검 콘솔 확인 · 안내 메시지 전송

## 목표 (Why)
응시자의 시험 환경 점검에서 `fail`/`warn`인 항목을 감독관·매니저·관리자가 콘솔에서 보고,
응시자에게 자유 입력 안내 메시지를 보내 응시자가 스스로 고치고 시험을 시작할 수 있게 한다.

- 대상: 보고 보내는 쪽은 감독관·매니저·관리자, 받는 쪽은 응시자
- 확인 시점
  - 입장 대기(점검) 중: 점검 진행 상태를 실시간으로 본다 (지금은 서버로 가지 않아 새로 올려야 함)
  - 시험 시작 후: 저장된 점검 결과(`ProctorConsent.envCheck`)를 본다
  - 메시지는 시험 전·중 모두 보낼 수 있다
- 메시지: 정해진 문구 없이 자유 입력
- 응시자 화면: 시험을 막지 않는 배너/토스트. 풀던 화면을 가리지 않고 시간도 멈추지 않는다. 응시자가 "확인"을 누르면 콘솔에 "읽음" 표시

## 완료 기준
- 콘솔에서 응시자별 점검 결과(통과·경고·실패 항목과 사유)를 볼 수 있다
- 메시지를 보내면 응시자 화면에 뜨고, 읽음 여부가 콘솔에 보인다

## 제약
- 기존 콘솔 폴링 방식과 응시자 쪽 프록터 채널을 최대한 활용한다
- 점검 진행 상태를 서버로 올리는 부분은 새로 만든다

## 하지 않을 것 (Out of scope)
- 응시자 답장·채팅
- 정해진 문구 목록
- 점검 기준(감도·임계값)을 콘솔에서 바꾸는 기능
- 메시지 이력 분석, 부정행위 판정과의 연동
