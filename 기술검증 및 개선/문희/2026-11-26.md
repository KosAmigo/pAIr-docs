# 2026-11-26 EC2 샌드박스 검증과 동시 실행 측정

- 대상: 샌드박스 서버(Ubuntu, `c7i-flex.large`, vCPU 2개, 메모리 3.7GB), systemd `pair-sandbox`, 동시 실행 상한 1
- 상세 결과: [설계/샌드박스_서버_운영.md](../../설계/샌드박스_서버_운영.md) 7절. 문서 커밋 `742c94d`, `4b46e7b`

## 문제

격리 시나리오는 맥과 자동 테스트(`SandboxIsolationTest`)에서만 확인했고, 운영하는 EC2 에서는 격리 항목 전체와 동시 실행 인원이 미확인이었다.
자동 테스트는 로컬 Docker 를 직접 부르기 때문에 운영 경로(systemd 서비스 → jar → `SandboxRunner` → 컨테이너)는 확인하지 못한다.

## 방법

| 결정 | 이유 | 수준 |
|---|---|---|
| 서버의 실행 API(`/internal/run`)에 나쁜 코드를 보내는 스크립트를 만들었다 | 운영 경로를 그대로 지나고, 서버에 `python3` 만 있으면 된다 | 논리 |
| 컨테이너 안에서 cgroup 값과 `/proc/self/status` 를 직접 읽는다 | 제한 옵션을 줬는지가 아니라 서버 커널에 적용됐는지를 본다 | 논리 |
| EC2 메타데이터(`169.254.169.254`) 접속 차단을 항목에 넣었다 | 닿으면 서버의 AWS 자격 증명을 읽을 수 있다 | 논리 |
| 제한을 푼 컨테이너로 대조 실험을 먼저 했다(맥) | 항상 통과하는 검사가 아닌지 확인. 네트워크·환경변수·권한·자원 제한 4개가 모두 실패했다. 나머지 항목은 대조 실험을 하지 않았다 | 측정 |

확인 스크립트(`isolation_check.py`, `load_test.py`)는 저장소에 넣지 않았다.

## 결과

| 확인 | 결과 | 수준 |
|---|---|---|
| 격리 11개 항목(토큰, 네트워크·메타데이터, 환경변수, 파일·권한, cgroup 제한값, 폭탄 코드, 무한 루프) | 모두 통과. 무한 루프는 45.1초에 중단 | 측정 |
| 서비스 프로세스의 환경변수 | 시스템 기본값과 `PAIR_RUN_REMOTE_TOKEN` 만 있음 | 측정 |
| 실행 중 서버 강제 종료 → systemd 재시작 | 15초 뒤 실행 컨테이너 없음 | 측정 |
| 실행 중 서버 강제 종료 → 서비스를 꺼 둠 | 직후에는 남아 있고 60초 뒤 없음(컨테이너 안 `timeout`) | 측정 |

### 동시 실행 (`order-deadlock` 정답 코드와 숨은 테스트, 대기 한도 60초, 단계마다 1번)

| 동시 요청 | 전체 | 응답 중앙값 | 응답 최대 | 결과 |
|---|---|---|---|---|
| 1 | 6.6초 | 6.6초 | 6.6초 | 성공 1 |
| 4 | 26.5초 | 16.6초 | 26.5초 | 성공 4 |
| 10 | 65.8초 | 36.4초 | 65.8초 | 성공 10 |
| 30 | 66.1초 | 60.0초 | 66.1초 | 성공 10, 503 거절 20 |

- 거의 동시에 들어온 요청은 약 10건까지 받는다(1분에 약 9건). 접속 응시자 수의 한계는 아니다. (측정)
- 개발 과제 시험은 10~15명이 적당하다고 본다. 1인당 2~3분에 한 번 누르고 서버를 50~70% 쓴다고 가정한 계산이다. (추정)

## 확인 중에 알게 된 것

- 샌드박스 서버도 관리 포트 8181 을 모든 주소에서 열고 `health`·`prometheus` 가 인증 없이 응답한다. 로컬에서 두 번째 서버를 띄우다 포트 충돌로 알았다(맥에서 확인). 운영 문서 보안 절에 적었다.

## 남은 것

- 보안 그룹 점검(8282 는 앱 서버만, 8181 은 인터넷 차단). 아직 확인하지 않았다.
- 시험 목표 인원 결정과 사양·동시 실행 상한 확정. 바꾼 구성은 다시 측정한다.
- 서버를 키우지 않는 개선 후보(모두 미측정): 1건의 단계별 시간 측정, Java 시작 옵션·시작용 캐시, 상한 2 측정, [빌드]를 샌드박스에서 분리, 중복 요청 차단, 대기 상태 표시.
- 측정하지 않은 것: 앱 서버를 거치는 시간, [빌드] 요청, 다른 과제, 몇 분 이상 이어지는 부하.
